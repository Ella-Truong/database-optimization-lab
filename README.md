# Database Optimization Lab

A hands-on repository for learning database design and optimization through experiments.

## Goals

- Practice database schema design
- Explore indexing and query optimization
- Measure latency and database performance
- Compare different design approaches and tradeoffs
- Understand how design decisions affect performance


## Approach

**Design → Query → Measure → Analyze → Redesign → Compare**

## Tools

- Node.js
- Prisma
- PostgreSQL
- Postman

This repository focuses on **database performance and design**, not UI or full application development.
